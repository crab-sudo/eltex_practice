# UDP Chat Server/Client Application

## Описание

Проект реализует простой чат между двумя клиентами через UDP сервер-посредник. Приложение состоит из:

- **Сервер** (`server.out`) - посредник между двумя клиентами, пересылает сообщения от одного клиента другому
- **Клиент** (`client.out`) - подключается к серверу и может отправлять/получать сообщения

### Особенности:
- Сервер ждет подключения двух клиентов, после чего начинает передавать сообщения между ними
- Каждый клиент запускает отдельный поток для приема сообщений
- Для завершения чата любой из клиентов может отправить сообщение "exit"

## Компиляция

### Способ 1: Использование Makefile
```bash
make
```

### Очистка
```bash
make clean
```

## Запуск

### Шаг 1: Запуск сервера
```bash
./server.out
```
Сервер запустится на порту 5000 и будет ждать подключения двух клиентов.

### Шаг 2: Запуск первого клиента (в отдельном терминале)
```bash
./client.out
```

### Шаг 3: Запуск второго клиента (в еще одном терминале)
```bash
./client.out
```

## Особенности реализации

### Сервер:
- Использует один сокет для всех клиентов
- Идентифицирует клиентов по их адресу и порту
- Ожидает подключения двух клиентов перед началом пересылки сообщений
- При получении "exit" от любого клиента отправляет команду завершения обоим

### Клиент:
- Использует два потока: основной для отправки сообщений, дополнительный для приема
- Автоматически завершает работу при получении "exit" от сервера
- Выводит полученные сообщения без прерывания ввода
