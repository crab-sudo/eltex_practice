# TCP File Transfer and Calculator Server

## Описание

Клиент-серверное приложение на основе TCP, предоставляющее три основные функции:
1. **Калькулятор** - выполнение базовых арифметических операций (+, -, *, /)
2. **Загрузка файлов** (PUT) - передача файлов с клиента на сервер
3. **Скачивание файлов** (GET) - получение файлов с сервера на клиент

Сервер поддерживает многопользовательскую работу через механизм `fork()`.

## Особенности реализации

### Безопасность и надежность
- Используются функции `sendall()` и `recvall()` для гарантированной передачи данных
- Создается директория `uploads/` для хранения загруженных файлов
- Проверка существования файлов перед операциями GET/PUT

## Использование клиента

После подключения клиент отображает меню:

```
Menu:
1) Calc (+ - * /)
2) Upload file to server (PUT)
3) Download file from server (GET)
4) Quit
Choice: 
```

### 1. Калькулятор
Ввод операции и двух чисел, пример:
```
Enter operation (one of + - * /): *
Enter first number: 12.5
Enter second number: 3.2
```
Сервер вернет результат: `RESULT 40`

### 2. Загрузка файла на сервер
```
Enter path to local file to upload: /home/user/document.txt
```
Файл будет сохранен на сервере как `uploads/document.txt`

### 3. Скачивание файла с сервера
```
Enter filename to download from server: document.txt
```
Файл будет скачан с сервера и сохранен локально с тем же именем.

### 4. Выход
Отправляет команду `QUIT` серверу и закрывает соединение.

## Особенности работы с файлами

### Загрузка (PUT):
1. Клиент отправляет команду `PUT`
2. Сервер отвечает `OK\n`
3. Клиент отправляет содержимое файла (бинарные данные)
4. Сервер подтверждает: `OK Uploaded <filename> <size> bytes\n`

### Скачивание (GET):
1. Клиент отправляет команду `GET`
2. Сервер отвечает `SIZE <size>\n` или `ERROR NotFound\n`
3. Клиент отправляет `OK\n`
4. Сервер передает файл (бинарные данные)
