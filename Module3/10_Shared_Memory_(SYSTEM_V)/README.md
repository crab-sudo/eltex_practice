# Задание 10: Разделяемая память System V

## Описание
Программа состоит из двух отдельных процессов:
- **Родительский процесс** (`parent.out`):
  - Генерирует наборы случайных чисел (от 1 до 100 чисел в диапазоне от -1000 до 1000)
  - Помещает набор в разделяемую память
  - Ждёт, пока дочерний процесс обработает данные
  - Выводит результаты на экран
- **Дочерний процесс** (`child.out`):
  - Находит минимальное и максимальное число в полученном наборе
  - Помещает результаты обратно в разделяемую память

Процесс повторяется до получения сигнала `SIGINT` (Ctrl+C), после чего выводится количество обработанных наборов.

## Компиляция и запуск

### Компиляция
```bash
make
```

### Запуск
1. **В первом терминале** запустите родительский процесс:
```bash
./parent.out
```

2. **Во втором терминале** запустите дочерний процесс:
```bash
./child.out
```

3. Для остановки нажмите `Ctrl+C` в терминале с родительским процессом.

### Очистка
```bash
make clean
```

## Важные моменты

### Синхронизация
- Используются два семафора System V для синхронизации:
  - `SEM_PARENT_TO_CHILD` (0) - сигнализирует, что данные готовы
  - `SEM_CHILD_TO_PARENT` (1) - сигнализирует, что обработка завершена

### Разделяемая память
- Создается файл `/tmp/shm_sets_ftok` для генерации ключа
- Размер структуры: `count + numbers[100] + min + max`
- Права доступа: 0666 (чтение/запись для всех)

### Завершение работы
- При получении SIGINT родительский процесс помещает `count = 0` в разделяемую память
- Оба процесса корректно освобождают ресурсы (разделяемую память, семафоры)
- Удаление разделяемых ресурсов выполняется родительским процессом

### Обработка прерываний
- Все операции с семафорами перезапускаются при получении сигнала (EINTR)
- Используется `volatile sig_atomic_t` для флага завершения
