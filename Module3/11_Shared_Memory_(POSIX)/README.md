# Задание 10: Разделяемая память POSIX

## Описание
Программа состоит из двух отдельных процессов, использующих **POSIX разделяемую память и семафоры**:
- **Родительский процесс** (`parent.out`):
  - Генерирует наборы случайных чисел (от 1 до 100 чисел в диапазоне от -1000 до 1000)
  - Помещает набор в разделяемую память
  - Ждёт, пока дочерний процесс обработает данные
  - Выводит результаты на экран
- **Дочерний процесс** (`child.out`):
  - Находит минимальное и максимальное число в полученном наборе
  - Помещает результаты обратно в разделяемую память

Процесс повторяется до получения сигнала `SIGINT` (Ctrl+C), после чего выводится количество обработанных наборов.

## Компиляция и запуск

### Компиляция
```bash
make
```

### Запуск
1. **В первом терминале** запустите родительский процесс:
```bash
./parent.out
```

2. **Во втором терминале** запустите дочерний процесс:
```bash
./child.out
```

3. Для остановки нажмите `Ctrl+C` в терминале с родительским процессом.

### Очистка
```bash
make clean
```
**Примечание:** После аварийного завершения программы могут остаться неубранные ресурсы. Для их очистки нужно выполнить:
```bash
rm -f /dev/shm/shm_sets
rm -f /dev/shm/sem.*
```

## Важные моменты

### Синхронизация
- Используются два **POSIX именованных семафора**:
  - `/SEM_PARENT_TO_CHILD` - сигнализирует, что данные готовы
  - `/SEM_CHILD_TO_PARENT` - сигнализирует, что обработка завершена

### Завершение работы
- При получении SIGINT родительский процесс помещает `count = 0` в разделяемую память
- Оба процесса корректно освобождают ресурсы
- Родительский процесс удаляет все разделяемые объекты
