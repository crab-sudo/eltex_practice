# Очередь с приоритетом и реализованным раунд-робином

## Принцип работы:
Функцией `insert   *char*   *priority (0-255)*` добавляются элементы в общий пул - саму очередь, в которой элементы разделяются на отдельные очереди по уровню приоритета.
		
Функция `enqueue` (И все её модификации) выгружают все элементы в общую очередь, расставляя элементы в порядке, согласно приоретету. Трафик распределяется только на непустые очереди изначалньой структуры. Также на то какая часть трафика будет выделена, влияет непосредственно сам уровень приоритета.
## Компиляция:
В терминале ***bash*** из директории с мэйкфайлом:

	make

## Запуск:
В программе предусмотрены два вида запуска: ***в ручном режиме*** и с использованием заранее заготовленных ***тестов***.

Ручной режим - все команды вводятся пользователем:

	./priority_queue       

Запуск заранее заготовленного теста - автоматически заполняет структуру значениями, запускает одну из функций выгрузки данных в общую очередь, и завершает работу программы:

	./priority_queue test1  // Вывод значения элемента из начала очереид
	./priority_queue test2  // Вывод значения первого элемента с приоритетом 17
	./priority_queue test3  // Вывод значений всех элементов с приоритетом не ниже 20
